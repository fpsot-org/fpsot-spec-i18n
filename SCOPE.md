# Scope

This Working Group develops the FPSOT internationalization specification.

The specification covers how FPSOT products show text, dates, numbers, amounts and lists in the language and conventions of each person: language tags, locale negotiation and fallback, formatting with Unicode CLDR data, message syntax for plurals and gender, translation files and their review, language markup, text direction, and personal names and postal addresses. It also sets that FPSOT products ship every user-visible text in English and French.

It does not cover how programs store or exchange dates, amounts or multilingual values, nor how to write the text itself.

Any changes of Scope are not retroactive.
