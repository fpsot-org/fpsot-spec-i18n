= FPSOT internationalization specification
include::_fpsot-terms.adoc[]

This specification sets how the products of {abbr-fpsot-first} show text and numbers in the language of each person.
It also sets how they store messages and exchange translations.
Every {abbr-fpsot} product ships in Canadian English and Canadian French, and the rules let contributors add any other {term-locale}.

The rules come in six parts.

* xref:language-tags.adoc[Language tags and locales] name languages and choose the one a person sees.
* xref:formatting.adoc[Formatting] covers how dates, numbers and amounts look.
* xref:messages.adoc[Messages] keep text out of the code and handle plurals and gender.
* xref:translation.adoc[Translation] covers both languages and the translation files.
* xref:markup.adoc[Text, markup and direction] declares languages and keeps characters intact.
* xref:names-addresses.adoc[Names and addresses] covers personal names and postal addresses.

The {abbr-fpsot} writing specification sets how to write the text itself.
This specification covers display only.
It does not set how programs store dates, amounts or text in two languages.

== Conformance

[quote, 'link:https://www.rfc-editor.org/info/rfc8174[RFC 8174]']
____
The key words "MUST", "MUST NOT", "REQUIRED", "SHALL", "SHALL NOT", "SHOULD", "SHOULD NOT", "RECOMMENDED", "NOT RECOMMENDED", "MAY", and "OPTIONAL" in this document are to be interpreted as described in BCP 14 (link:https://www.rfc-editor.org/info/rfc2119[RFC 2119], link:https://www.rfc-editor.org/info/rfc8174[RFC 8174]) when, and only when, they appear in all capitals, as shown here.
____

The keywords follow requirement WRT-010 of the {abbr-fpsot} writing specification.
The French version uses the French keywords of WRT-011.

A product conforms to this specification when it meets every MUST rule.
Rules that name an {abbr-fpsot} product, such as LOC-003 and LOC-030, apply to products that {abbr-fpsot} publishes.
Other products meet them when they claim the same two languages.
