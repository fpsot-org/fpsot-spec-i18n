= FPSOT internationalization specification

Rules for showing text, dates and numbers in the language of each person in FPSOT products: language tags, locale negotiation and fallback, CLDR formatting, MessageFormat messages, translation files, text direction, and personal names and postal addresses.
Every FPSOT product ships in Canadian English and Canadian French.
Version 0.1 is a draft.

== Implement this spec

Read the normative text in `spec/en/` or `spec/fr/`.
Start with `index.adoc`, then read the six parts.
Each requirement has an ID from `LOC-001` to `LOC-055`.
Check your product against every MUST rule.

== Adopt this spec

Read the guide in `docs/modules/en/pages/index.adoc` or `docs/modules/fr/pages/index.adoc`.
It shows the main steps for a product in English and French.
The comparison pages show how the rules of Canada and Québec relate to each requirement.

== Layout

[cols="1,3"]
|===
| Folder | Content

| `spec/`
| Normative text, in English and French. `book.adoc` joins the pages into one book.

| `docs/`
| Guides, in the Antora folder layout.

| `skill/`
| The agent skill: a short summary that cites requirement IDs.

| `rules/`
| Machine-checkable rules. None yet.

| `diagrams/`
| PlantUML sources and their rendered SVG files. None yet.

| `jurisdictions/`
| Comparison data: the international baseline, Canada and Québec.
|===
